# Lullabies PWA Project

A Progressive Web App (PWA) designed for offline use on mobile devices, specifically for choosing bedtime music for children.

## Project Overview

- **Name**: Lullabies
- **Description**: Bedtime music chooser for my daughter
- **Type**: Progressive Web App (PWA)
- **Platform**: Mobile devices
- **Features**:
  - Works offline after installation
  - Audio/video playback
  - Service worker for caching
  - Manifest for app installation
  - Responsive design for mobile

## Technology Stack

### Frontend Framework
- **Framework**: React.js (via Vite)
- **Build Tool**: Vite
- **PWA Plugin**: vite-plugin-pwa

## Key Files

### vite.config.js
- Configures Vite with React and PWA
- Sets up service worker generation
- Defines workbox caching strategy
- Sets up manifest with app metadata

### public/sw.js
- Development service worker (not auto-generated)
- Contains basic install event handling
- Note: Production SW is auto-generated by vite-plugin-pwa

### public/manifest.webmanifest
- Web app manifest for PWA installation
- Contains app name, icons, theme colors
- Required for mobile app installation

## PWA Configuration

### Service Worker
- **Type**: Cache-first strategy for assets
- **Video Caching**: Maximum 50MB (videos are largest assets)
- **Fonts**: Google Fonts cached for 1 year
- **Image Optimization**: CDN integration

### Manifest Properties
- `name`: "Lullabies"
- `short_name`: "Lullabies"
- `description`: "Bedtime music chooser for my daughter"
- `display`: "standalone" (runs as standalone app)
- `orientation`: "portrait"
- `theme_color`: "#1a1a2e"
- `background_color": "#1a1a2e"

### Icons
- 192x192: favicon.svg
- 512x512: favicon.svg

## Build Process

1. **Development**: `npm run dev`
   - Vite server with React Fast Refresh
   - Hot reload for rapid development

2. **Production Build**: `npm run build`
   - Generates optimized build in `dist/`
   - Auto-generates service worker
   - Creates web app manifest
   - Files minified and bundled

3. **Preview**: `npm run preview`
   - Test production build locally

## Deployment for Mobile

### Offline Support
- Installable as native mobile app
- All assets cached by service worker
- Works without internet connection

### Mobile Optimization
- Viewport meta tag configured
- Apple mobile web app tags
- Touch-friendly UI
- Portrait orientation locked

## Development Notes

- Uses Vite's React plugin for fast development
- PWA plugin handles all service worker generation
- Assets up to 50MB are cached (primarily videos)
- Google Fonts integrated for typography
- Custom SVG icons for app branding

## Issues and Limitations

1. **Audio/Video Licensing**: Ensure all content has proper licensing
2. **Storage**: Large video files may consume significant device storage
3. **Performance**: Initial install may take time due to large asset caching
4. **Mobile-Specific**: Tested primarily with iOS Safari and Android Chrome
